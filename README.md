# Jasper Rosales - Portfolio

A one-page portfolio that shows how I improve technology and businesses — with a 3D / 2D toggle for the hero and a mobile-friendly layout.

## Features

- One-page portfolio: Improvements, Projects, Experience & Education, Certifications & Recognitions, Contact
- Projects presented as improvements: what changed and what it delivers for companies and people
- Hero with a **3D** version (Rubik's cube) and a **2D** version — switchable with a toggle
- Mobile-friendly responsive design
